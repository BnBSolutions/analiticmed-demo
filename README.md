# AnaliticMed – Demo version

Website redesign for Clinica Medicală AnaliticMed (analiticmed.md), Bălți.

Developed by BNB Innovate.

The site uses React Router in SPA mode and supports direct route loading on static hosts.

## Development

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```
